# L9 / High-Elo Streamer Lingo Guide
## Voice Reference: Drututt, NattyNat, Detert, Sanchovies, Humzh

This is the vocabulary and tone used by high-elo EUW/NA top lane streamers. The guide should sound like it was written by someone who actually plays the game at a high level, not a corporate wiki.

---

## INTENSIFIER PREFIXES (stack these)

- **turbo** = very/extremely → "turbo gapped", "turbo cancer", "turbo free"
- **giga** = even more than turbo → "giga broken", "giga diff"  
- **omega** = beyond giga (rarely used, for emphasis) → "omega diffed"
- **perma** = constantly/all the time → "perma push", "perma shove", "perma proxy"
- **hard** = strongly → "hard stomp", "hard outscale", "hard diff"

## KEY VOCABULARY

### Matchup/Champion Talk
- **diff** = difference → "champ diff", "hands diff", "jg diff", "top diff"
- **gapped** = outclassed → "you just get gapped", "he gets turbo gapped"
- **ego** (verb) = play overconfidently → "don't ego this", "if you ego he kills you"
- **ego check** = getting punished for cocky play → "this matchup is a massive ego check"
- **hands** = mechanical skill → "it's a hands diff", "need hands for this"
- **spacing** = positioning/distance control → "just spacing him out"
- **angle** = opportunity/play → "look for an angle", "there's no angle here"
- **bonk** = chunk with damage → "bonk him level 1", "one bonk and he's zoned"
- **running it** = inting/dying repeatedly → "he's just running it"
- **limit testing** = playing aggressively (sometimes excuse for inting) → "I'm limit testing bro"
- **mental boom** / **mental** = tilted → "his mental goes boom", "mental diff"
- **chilling** = doing well / safe state → "you're just chilling", "we're chilling"
- **doomed** = hopeless → "it's doomed", "turbo doomed", "lane is doomed"
- **abomination** = disgusting champion → "this champ is an abomination"
- **rat** = ranged top laner → "rat champ", "disgusting rat"
- **degenerate** = annoying/cheese playstyle → "degenerate matchup"
- **go next** = give up (mental) → "just go next in champ select"
- **brainless** = no skill required → "brainless champ", "brainless lane"
- **piss on** = stomp/dominate → "you just piss on him"
- **coinflip** = 50/50 outcome → "it's a coinflip lane"
- **we ball** = let's go, playing aggressive → "we ball level 1"
- **cooking** = doing something smart/creative → "he's cooking"
- **int** / **inting** = dying (sometimes intentionally, sometimes just dying) → "you int if you ego"
- **just chill** = play safe, farm → "just chill and scale"

### Item/Build Talk  
- **spike** = power spike → "huge spike", "1 item spike"
- **rush** = build first → "rush Liandry's", "rush chain vest"
- **sit on** = hold component without completing → "sit on Negatron"
- **grief** = bad decision → "it's grief to build X", "griefing if you fight here"

### Lane State Talk
- **prio** = priority (wave control) → "he has perma prio"
- **crash** = push wave into tower → "crash and proxy"
- **bounce** = wave bouncing back → "let it bounce off turret"
- **tempo** = time/speed advantage → "don't lose tempo"
- **chain** = chain CC or combo → "he chains you"

## TONE & VOICE RULES

1. **Casual, not corporate.** "He turbo gaps you" not "This is a challenging matchup"
2. **Hyperbolic.** Everything is either the best or worst thing ever
3. **Direct.** Short sentences. No fluff. Tell them what to do.
4. **Confident.** Write like you've played 2000 games of this matchup
5. **Funny when natural.** Dark humor, self-deprecating, ironic
6. **Swearing is earned.** "This matchup is fucking free" hits different from generic swearing
7. **Reference "hands" and "ego" constantly.** These are the two things that decide every lane
8. **Use "you" directly.** Talk to the reader like a coach. "You just chill. You scale. You win 5v5."
9. **Don't sugarcoat.** If a matchup is unplayable, say "dodge" not "consider alternative strategies"
10. **Champion names are casual.** "Heimer", "GP", "Morde", "Renek" — not full names
