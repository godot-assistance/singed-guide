## Key Meta Changes

### 1. Protoplasm Harness (NEW ITEM)
- **Cost:** 2500g (Kindlegem + Giant's Belt + 800g)
- **Stats:** 600 HP, 20 ability haste (buffed from 15 in 26.3)
- **Passive (Lifeline):** When low HP: heals 200-400 (+175 armor/MR scaling), grants MS + tenacity
- **Synergy:** Perfect for Singed's "run at them while low HP" playstyle
- **Win Rate:** 58.43% overall, 64.6% WR when built 3rd item

**Replaced Demonic Embrace in:** 47 matchups (68% of database)

### 2. Ultimate Grievous Wounds Nerf
- **Old:** 40% Grievous Wounds
- **New:** 25% Grievous Wounds
- **Impact:** Morellonomicon now MANDATORY vs healers (ult GW is supplementary only)

**Updated GW references in:** 7 matchups (Dr. Mundo, Garen, Gragas, Tahm Kench, Volibear, Warwick, Aatrox)

### 3. Rune Optimization
**Default Rune Page (Patch 26.3 Standard):**
- **Primary (Precision):** Conqueror → Presence of Mind → Legend: Alacrity → Last Stand
- **Secondary (Sorcery):** Nimbus Cloak + Celerity
- **Shards:** Attack Speed + Adaptive/Armor/MR + Health/Tenacity

**Phase Rush Reserved For:** Darius, Illaoi, Renekton, Sett, Camille, Jax (situational escape matchups)
